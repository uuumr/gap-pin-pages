常见问题

如何备份我的装修数据？

在「设置 → 数据备份」中可导出 JSON（可恢复的完整备份）、Excel（CSV）或 PDF 报表。

如何恢复备份？

在「设置 → 数据备份 → 导入数据」中选择之前导出的 JSON 文件即可覆盖恢复。

想重新开始怎么办？

「设置 → 清空数据」会清空全部分类、条目、待办和记账，并恢复默认分类；也可在「装修模板」中一键应用半包或全包清单。

会员购买后没有生效？

请尝试点击「恢复购买」，并确保 Apple ID 登录状态与购买时一致。未购买时 App 自首次打开起提供 30 天试用。

图片无法添加？

请在系统「设置 → 隐私与安全性 → 照片」中允许本 App 访问所选照片，或重新选择相册权限。

待办会提醒我吗？

目前待办日期以日历和计划页可视化为主，暂不发送系统推送通知；后续版本可考虑加入提醒。

FAQ

How do I back up my renovation data?

In "Settings → Data Backup" you can export JSON (a full restorable backup), Excel (CSV), or a PDF report.

How do I restore a backup?

Choose "Settings → Data Backup → Import Data" and select a previously exported JSON file to restore and overwrite.

How do I start over?

"Settings → Clear Data" clears all categories, entries, todos, and expenses and restores default categories. You can also apply a half-package or full-package template under "Renovation Templates".

Why didn’t premium unlock after purchase?

Try "Restore Purchase" and make sure you are signed in with the same Apple ID used for the purchase. The app offers a 30-day trial from first launch if not purchased.

Why can’t I add photos?

In "Settings → Privacy & Security → Photos", allow this app to access the selected photos, or re-pick the photo permission.

Will I be reminded about todos?

Todo dates are currently visualized in the calendar and plan views; push notifications are not yet sent. Reminders may be added in a future version.
